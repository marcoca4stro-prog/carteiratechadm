# CarteiraTech

Landing page estática do projeto escolar CarteiraTech, pronta para publicação no GitHub Pages.

## Visualizar localmente

Abra `index.html` no navegador ou use um servidor estático, por exemplo:

```powershell
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Publicar no GitHub Pages

1. Envie todos os arquivos deste diretório para um repositório público no GitHub.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.

O endereço será exibido pelo GitHub quando a publicação terminar.
